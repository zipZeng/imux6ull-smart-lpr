# 联调与延迟

可复现的一组参数：`/dev/video1` 读取 YUYV、640×480、10 fps，编成 4:2:0 MJPEG 后走 RTSP/TCP。格式表里的 MJPEG 没有帧，不能 `-c:v copy`。设备节点是开发板 USB Host 上的 `/dev/video1`。

## 当前的公网服务器

MediaMTX 在轻量应用服务器上，地域广州，公网 IPv4 是 `134.175.47.224`，系统是 Ubuntu。程序目录是 `~/imux6ull-smart-lpr/`，里面是 `mediamtx` 和从仓库拷去的 `server/mediamtx.yml`。配置文件不用改 IP。

防火墙放行入站 TCP 8554。实例带宽 4 Mbps，每月流量 300 GB。一路画面要算两次：开发板推上去一份，上位机再拉走一份。测试彩条若不用 `-re`、按几十倍速推，会立刻顶满这 4 Mbps，播放器就会丢帧卡顿。真实摄像头保持 10 fps。全天推流会在几天内用完 300 GB。

关掉 SSH 后要继续听端口：

```bash
cd ~/imux6ull-smart-lpr
nohup ./mediamtx mediamtx.yml > mediamtx.log 2>&1 &
```

开发板连上热点后推流：

```bash
./board/stream.sh rtsp://134.175.47.224:8554/live
```

Linux 和 Windows 的 Qt 上位机地址栏默认就是这同一个地址。没有上位机时，VLC 用 `vlc --rtsp-tcp rtsp://134.175.47.224:8554/live`。

`mediamtx.yml` 里没有写死客户端地址。换服务器时只改推流脚本的参数；上位机地址栏里的 IP 一起改。

## 本机自测

只在同一台电脑上证明 MediaMTX 能收流时，把地址写成 `127.0.0.1`：

```bash
./mediamtx server/mediamtx.yml
./board/stream.sh rtsp://127.0.0.1:8554/live
```

上位机地址栏改成 `rtsp://127.0.0.1:8554/live`。默认值是公网地址，本机自测要手改。

## 缓冲

板端 `board/stream.sh` 封装时加了 `-muxdelay 0 -muxpreload 0`。采集前不再加 `-fflags nobuffer`，那会让摄像头探测更拿不到帧。客户端拉流使用 FFmpeg 的 TCP、`nobuffer`、`low_delay`，并把 `CAP_PROP_BUFFERSIZE` 设为 1。定位大约每 200 ms 取最新一帧，显示仍按拉流帧率刷新。

要改分辨率或帧率：

```bash
VIDEO_SIZE=640x480 VIDEO_FPS=10 ./board/stream.sh rtsp://<服务器IP>:8554/live
```

## UDP

默认全程 TCP。要对比 UDP：

1. 把 `server/mediamtx.yml` 的 `rtspTransports` 改成 `[udp, tcp]`，然后重启 MediaMTX。
2. 板上执行 `RTSP_TRANSPORT=udp ./board/stream.sh rtsp://<服务器IP>:8554/live`。
3. 客户端执行 `LPR_RTSP_TRANSPORT=udp ./client/build/lpr_client`。

UDP 打不通时改回 TCP 即可，不用改代码。

## 客户端编译

Linux 和 Windows 编译同一份 `client/`。Linux 用 Qt 5：

```bash
sudo apt install build-essential cmake qtbase5-dev libopencv-dev
cmake -S client -B client/build
cmake --build client/build
./client/build/lpr_client
```

Windows 用 Qt 6，并且只拷 `client/CMakeLists.txt` 和 `client/src/`。`client/build` 若是从 Linux 拷来的，先删掉，否则 CMake 会拒绝使用里面的 Linux 缓存。默认的 Qt、OpenCV 路径写在 `client/CMakeLists.txt` 的 `QT_ROOT` 和 `OpenCV_DIR`。

```bat
cmake -S client -B client\build -G "Visual Studio 17 2022" -A x64
cmake --build client\build --config Release
```

`client\build\Release\lpr_client.exe` 旁边有 Qt 运行库和 `opencv_videoio_ffmpeg4100_64.dll`，换一台 Windows 电脑时把这个目录一起拷走。没有那份 FFmpeg DLL 时，窗口能开，RTSP 打不开。
