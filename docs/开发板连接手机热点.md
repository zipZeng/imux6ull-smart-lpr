# 开发板连接手机热点

每次给 i.MX6ULL（100ask）上电、并打开手机热点时，按本文把 `wlan1` 连上。下面的 `insmod`、`wpa_supplicant`、`udhcpc` 都在串口里逐条执行，仓库没有把它们收成脚本。开发板上属于本仓库的文件只有拷过去的 `board/stream.sh`。网卡是 USB 上的 8188EU，驱动文件是板上的 `/root/8188eu.ko`。热点名称、密码和加密方式写在 `/etc/wpa_supplicant.conf`，命令行里不再填写密码。

这块网卡只有 2.4 GHz，只接 WPA2。配置文件里的 `ssid` 当前是 `Redmi_K60E`。换热点时先改这个文件，再按下面的步骤连接。

拿到地址之后，推流命令是 `./stream.sh rtsp://134.175.47.224:8554/live`。MediaMTX 在这台公网服务器上，启动方式见 [README.md](../README.md)。本文停在开发板拿到 IP。

## 1. 先开手机热点

1. 打开便携式热点。名称与 `/etc/wpa_supplicant.conf` 里的 `ssid` 一致，当前是 `Redmi_K60E`。
2. 安全性选 **WPA2-Personal**。
3. 频段选 **2.4 GHz**。
4. 若系统有「锁屏后关闭热点」或空闲自动关闭，关掉它。
5. 手机放在开发板旁边。信号大约 -90 dBm 时地址仍能拿到，后面的视频流容易断。

热点先开着，再操作开发板。

## 2. 加载驱动

串口登录后执行：

```sh
insmod /root/8188eu.ko
```

内核日志里接口会从 `wlan0` 改名为 `wlan1`，并打印 `MAC Address = 60:42:7f:68:5d:ff`。下面两句可以忽略，继续下一步：

- `IPv6: ADDRCONF(NETDEV_UP): wlan1: link is not ready`
- `R8188EU: INFO indicate disassoc`

`insmod` 若提示 `File exists`，驱动已经在内核里，不要重复加载，直接做第 3 步。

确认接口已经叫 `wlan1`：

```sh
ifconfig wlan1 up
```

`ifconfig -a` 里没有 `wlan1` 时，看 USB 网卡是否插好，再执行一次 `insmod`。

## 3. 连接热点

开机后系统自己会有一个 `/usr/sbin/wpa_supplicant -u`。它不占用 `wlan1`，留着。手动连接只用这一条：

```sh
wpa_supplicant -Dwext -B -i wlan1 -c /etc/wpa_supplicant.conf
```

这三句可以忽略：

- `rfkill: Cannot get wiphy information`
- `ioctl[SIOCSIWAP]: Operation not permitted`
- `ioctl[SIOCSIWENCODEEXT]: Invalid argument`

接着看内核日志，应出现：

```text
R8188EU: INFO assoc success
IPv6: ADDRCONF(NETDEV_CHANGE): wlan1: link becomes ready
```

再确认已经连上：

```sh
iwconfig wlan1
```

成功时 ESSID 是 `"Redmi_K60E"`，Access Point 是一串 MAC，不是 `Not-Associated`。`Security mode:open` 是这块驱动的显示问题；密钥那一行有内容，说明加密已经生效。

## 4. 获取地址

```sh
udhcpc -i wlan1
```

成功时会打印租约，例如：

```text
udhcpc: lease of 192.168.172.229 obtained
```

最后核对：

```sh
ifconfig wlan1
```

应同时有 `RUNNING` 和 `inet addr`。到这里网络就通了，再推流：

```sh
./stream.sh rtsp://134.175.47.224:8554/live
```

服务器日志出现 `is publishing to path 'live'` 后，在 Linux 或 Windows 上打开 Qt 上位机。地址栏默认就是这个 URL。

## 同一次开机里重新连接

驱动还在时不要再 `insmod`。先停掉手动启动的那个，再重连：

```sh
killall wpa_supplicant
ifconfig wlan1 up
wpa_supplicant -Dwext -B -i wlan1 -c /etc/wpa_supplicant.conf
iwconfig wlan1
udhcpc -i wlan1
```

系统自带的 `wpa_supplicant -u` 若被一起停掉，不影响这次手动连接。

## 卡住时看哪里

| 现象 | 处理 |
| --- | --- |
| `iwconfig` 仍是 `unassociated`，或 `iwlist wlan1 scan` 里没有 `Redmi_K60E` | 热点没开、名称和配置文件不一致，或频段在 5 GHz。改回 2.4 GHz 后重新扫描，看到名字再启动 `wpa_supplicant` |
| 扫描里有名字，但马上 `disassoc`，`udhcpc` 只有 `sending discover` | 对照手机上的热点密码和 `/etc/wpa_supplicant.conf` 里的 `psk` |
| `udhcpc` 一直没有 `lease of` | 先看 `iwconfig`。还没关联上就不要要地址 |
| 有地址，推流一会儿就断 | 看 `iwconfig wlan1` 的 `Signal level`。把手机移近开发板 |
